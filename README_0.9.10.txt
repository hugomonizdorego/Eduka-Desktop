Edukasaun Desktop Suite 0.9.10

All included components use the same version number:
- Eduka-Desktop 0.9.10
- Eduka-Panel 0.9.10
- Eduka-Menu 0.9.10
- Eduka-Menu-Settings 0.9.10

Changes in this patch:
- Randomized category and Grid/List accent colors for every desktop session using one shared bright palette.
- Removed the black hover glitch by replacing transparent radial fills with safe opaque pastel highlights.
- Replaced old visual-theme choices with Eduka-Default-Theme and Liquid Glass.
- Added an LXQt-native Liquid Glass appearance with tint, bright glass rims, shadows and compositor blur hints.
- Added a 4 GB RAM/two-thread safety check and confirmation before Liquid Glass can be enabled.
- Made Eduka-Menu Settings minimizable, visible in the taskbar and single-instance; repeated launches restore the existing window.
- Integrated the Eduka Update System v1 panel notification protocol and official update-available icon.
- Force-repaired panel stacking without resizing applications: fullscreen apps and overlapping large apps on small screens take priority.
- Retained the 0.54 Eduka-Panel transparency default.
- Preserved accessibility, Orca pacing, List readability, taskbar restore/minimize, adaptive Grid, About, context menus and clean System Information.

Development continues toward Final Version 1.1 in November 2026.
